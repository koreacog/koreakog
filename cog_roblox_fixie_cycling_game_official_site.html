로블록스 코그 조작법 안내

코그(COG)는 자전거를 타고 배달과 화려한 트릭을 즐기는 게임입니다.
PC, 콘솔, 모바일 각 기기별 맞춤 조작 키를 확인하세요.

PC 조작법

키보드 및 마우스
  • 이동 W / A / S / D
  • 자전거 점프 H
  • 트릭 (피쉬 앤 칩스) Z
  • 트릭 (와일리) X
  • 스탠드 C
  • 바디 뷰 시점 V
  • 슬라이드 LSHIFT
  • 스프링 / 스프린트 LCTRL (길게)

콘솔 조작법

Xbox / PlayStation
  • 페달 (가속) R1 버튼
  • 브레이크 L1 버튼
  • 조향 (방향 전환) 좌측 조이스틱
  • 트릭 (피쉬 앤 칩스) X 버튼
  • 점프 점프 버튼 (뛰기)
  • 스탠드 B 버튼

모바일/태블릿

터치 화면 조작
  • 이동 좌측 원형 조이스틱
  • 시점 전환 빈 화면 밀기
  • 점프 우측하단 위 화살표
  • 화면 확대 / 축소 두 손가락 오므리기/펼치기
